# 竞品月销量流程

本草案根据飞书应用身份实际读取的字段定义编排。运行参数为目标月份（`YYYY-MM`）。四张表按角色绑定，凭证通过本机配置传入。

## 执行 2026-10 样例

在仓库根目录运行。执行 `npm ci` 安装锁定依赖后，示例使用项目内置的 OpenCLI 和通用插件。现有包位于 `examples/competitor-sales-2026-10.flow`。

```sh
node examples/competitor-sales.ts pack
node --env-file=.env examples/competitor-sales.ts preview
node --env-file=.env examples/competitor-sales.ts replay
node --env-file=.env examples/competitor-sales.ts replay examples/competitor-sales-2026-10.flow X2max
```

`preview` 最多取两个站点 ASIN，输出拟写入数据。 `replay` 获取全部在监控且已配置站点 ASIN 的竞品，先完成取数，再写入指定的明细和汇总表。本次写入测试的执行入口只执行新增和更新，过期清理步骤仍待实现。凭证变量为 `LARK_APP_ID`、`LARK_APP_SECRET` 和 `SELLERSPRITE_SECRET_KEY`。

## 步骤

1. **读取汇率表。** 分页读记录。用站点列对应的国家查找汇率记录，取代码、货币、汇率。运行前核对国家到站点代码的对应关系，以及汇率的换算方向。
2. **读取监控表。** 分页读记录。将七个站点列展开为逐站点的竞品请求，保留产品名、产品线和公司。监控状态的有效值、站点单元格是 ASIN 还是 URL，需用实际记录样例确认。
3. **读取卖家精灵月销量。** 按站点和 ASIN 调用 `asin_sales_trend`，从 `salesTrendPoints` 选取目标月份。优先使用子体销量和销额。子体数据缺失时，仅在返回的父 ASIN 等于查询 ASIN 且只有一个变体时使用父体指标。飞书列表按返回游标分页，已验证的卖家精灵响应一次返回月度序列。缺少可用月数据时停止写入并显示诊断。
4. **生成并写入明细。** 月份、商品链接和产品名写入文本字段，销量、单价、销额（原币）、汇率和销额（CNY）以数字写入。平台和币种使用标准化名称，正式运行允许动态扩展单选选项，试跑预览拟新增的选项。先核对「月份 + 平台 + 商品链接」在现有记录中的唯一性，再用匹配得到的 `record_id` 更新。
5. **生成并写入汇总。** 将月份、产品名、产品线和公司写入文本字段，销量、客单价和预估销额写入同名数字字段。建议按「月份 + 产品名 + 产品线 + 公司」分组，销量取明细销量之和，预估销额取人民币销额之和，客单价用预估销额除以销量。分组键、币种口径和零销量处理在实现时验证。
6. **预览并清理旧明细。** 以明细的文本月份列筛选候选记录，按 `record_id` 清理。三个月的计算基准与临界月归属在实现时确认。正式执行在明细和汇总写入成功后才清理，试跑只展示候选记录。

本草案已通过飞书应用身份复核字段结构。单选动态扩展的实际写入行为、行数据、卖家精灵实际响应、汇总口径与清理边界仍待验证。
